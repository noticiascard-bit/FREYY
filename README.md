FREYY

FREYY é um Security Toolkit desenvolvido em Python para Termux, reunindo ferramentas e módulos de análise de segurança em uma interface de terminal.

🛠️ Recursos

- OSINT
- Network
- Web Security
- Vulnerability
- Network Monitor
- File Analyzer
- APK Analyzer
- Chat AI

📱 Requisitos

- Android
- Termux
- Python 3
- Git

📦 Instalação

Clone o repositório:

git clone https://github.com/noticiascard-bit/FREYY.git
cd FREYY

Instale as dependências necessárias:

pkg update
pkg install python git nmap

🚀 Executando

Dentro da pasta do projeto:

python freyy.py

🔐 Chat AI

O módulo Chat AI utiliza uma chave da API do Gemini.

A chave não deve ser colocada diretamente no código ou publicada no GitHub.

Configure a variável de ambiente:

export GEMINI_API_KEY="SUA_CHAVE_AQUI"

Ou utilize o método de configuração de chave suportado pelo próprio FREYY.
